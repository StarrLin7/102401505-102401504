# 校园失物招领

福州大学软件工程第二次结对作业。项目以第一次结对作业原型为基础，实现“发布信息 → 浏览或搜索 → 查看详情 → 联系发布者 → 更新状态”的完整流程。

## 功能

- 发布寻物与招领信息，并校验必填项和 11 位手机号。
- 首页集中浏览，支持寻物/招领切换。
- 搜索页支持关键词、信息类型和地点组合筛选。
- 详情页展示完整信息和联系方式，可一键复制联系方式。
- “我的发布”中可将本人信息标记为“已找到”或“已归还”。
- 使用 localStorage 保存数据；首页提供全部、待解决、已解决统计。

## 运行环境

- 推荐浏览器：Google Chrome（最新版）。
- 无需 Node.js、npm、后端服务或网络环境；双击 HTML 文件即可运行。
- 请保持 `index.html`、`src/` 与 `tests/` 的相对目录关系不变。

## 测试人员操作指南

1. 下载 ZIP 并解压，或执行 `git clone` 获取整个仓库。
2. 双击根目录的 `index.html`，用 Google Chrome 打开。首页出现三条演示数据即表示程序启动成功。
3. 点击顶部搜索栏：输入关键词，并依次选择“寻物/招领”和地点，验证组合筛选与空结果提示。
4. 点击任意卡片进入详情：首次点击“联系发布者”显示号码；再次点击可复制联系方式。
5. 点击底部“发布”：填写全部字段并使用 11 位手机号，提交后可在详情页看到新信息；故意填写错误手机号可验证校验提示。
6. 点击“我的发布”：打开林金晶发布的信息，在详情页点击“标记为已找到/已归还”，返回首页可看到统计数字和状态同步更新。
7. 双击 `tests/store.test.html`，页面底部应显示 **“结果：12/12 通过”**。

## 数据与重置说明

- 所有发布和状态数据只保存在当前浏览器的 `localStorage`，刷新页面后仍保留，不会上传到服务器。
- 如需恢复三条演示数据，请在 Chrome 中打开开发者工具 → Application → Local Storage，删除键名 `campus-lost-found-102401505-102401504-posts-v1` 后刷新页面。
