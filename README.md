# 校园失物招领

福州大学软件工程第二次结对作业。项目以第一次结对作业原型为基础，实现“发布信息 → 浏览或搜索 → 查看详情 → 联系发布者 → 更新状态”的完整流程。

## 功能

- 发布寻物与招领信息，并校验必填项和 11 位手机号。
- 首页集中浏览，支持寻物/招领切换。
- 搜索页支持关键词、信息类型和地点组合筛选。
- 详情页展示完整信息和联系方式，可一键复制联系方式。
- “我的发布”中可将本人信息标记为“已找到”或“已归还”。
- 使用 localStorage 保存数据；首页提供全部、待解决、已解决统计。

## 使用说明

1. 下载或克隆整个项目，保持目录结构不变。
2. 使用 Google Chrome 直接打开 `index.html`，无需安装依赖或启动服务。
3. 首页可浏览信息；点击搜索可按关键词、类型、地点筛选；点击卡片查看详情。
4. 在底部“发布”完整填写表单，手机号格式正确后即可发布。
5. 在“我的发布”或本人信息详情中更新状态。数据保存在当前浏览器 localStorage，刷新后仍保留。
6. 用 Chrome 打开 `tests/store.test.html` 可查看 12 条单元测试结果。

## 技术说明

项目仅使用 HTML、CSS 和原生 JavaScript，不依赖框架或构建工具，以保证测试人员下载后可直接运行。
